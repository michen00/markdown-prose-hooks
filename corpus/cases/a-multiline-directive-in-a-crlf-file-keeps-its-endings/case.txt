name: A multi-line directive in a CRLF file keeps every ending it arrived with
why: The comment is read across lines, so an implementation that accumulated its content from the raw lines would carry a trailing carriage return into the match and stop recognizing the marker in exactly the files where a break matters most. Every line here is emitted as the bytes it arrived as, and the paragraph after the exempt one is joined onto a CRLF terminator rather than an LF one. Bytes on disk rather than an assertion about them, because a case written in LF would pass against an implementation that rewrote the file.
paragraphs_unwrapped: 1
line_breaks_removed: 1
