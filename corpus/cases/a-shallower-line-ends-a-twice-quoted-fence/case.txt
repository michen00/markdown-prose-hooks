name: A line quoted less deeply than the fence it sits under ends it
why: Container state is dropped when the quote ends, and a line carrying fewer markers than the container's own depth is that same event written with one marker rather than with none -- the inner quote ends there and the fence ends with it. CommonMark reads it that way, measured: a fence takes no lazy continuation, so the shallower line renders as a paragraph in the outer quote and the comment under it as a comment rather than as code. Gating the close on the container's depth without gating the drop the same way left "no marker at all" and "fewer markers than the container" meaning different things, and only the second one lost anything: the live marker below such a line was read as code and the break the author had marked was joined away. Prettier ends the fence here too, measured, and joins the paragraph below anyway, because its marker is a sibling of the block the comment sits in rather than of the paragraph -- the difference the directive section of the readme already records, and the direction in which this tool declines.
