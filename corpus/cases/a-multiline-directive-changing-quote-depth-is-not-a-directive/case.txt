name: A multi-line directive whose quote depth changes mid-comment is not a directive
why: The whole marker stack comes off every line, so the deeper line would read as the bare marker on its own -- and that is exactly why the stack has to be the same one on every line of the comment. An implementation that stripped whatever stack each line happened to carry would read this as the marker and exempt a paragraph nobody marked; prettier joins it too, measured. One character separates it from `a-quoted-multiline-directive-exempts-the-quoted-paragraph`, which is exempt, and the answers are opposite.
